## Описание

Мощен, бърз search engine върху рекуирмънтите: пълнотекстово търсене (заглавие, описание, критерии), търсене по ID/префикс/статус/приоритет/отговорник, по връзки (Родител/Зависи от) и филтри. Целта е навигация в големи requirements бази. **Това е future feature — НЕ се имплементира в текущата итерация.**

## Архитектурно изискване (критично)

За да може search engine-ът да се добави нативно и лесно в бъдеще, още сега архитектурата трябва да гарантира:
1. Parser-ът произвежда **структурирани, нормализирани записи** (всички полета + връзки), а не само суров текст.
2. Моделът на данните е **индексируем**: стабилни ID, нормализирани полета, ясни връзки.
3. Search/Index/Graph/Export са **консуматори на един и същ структуриран data source** — не парсват markdown наново.

## Acceptance Criteria (за бъдещата имплементация — not now)

- [ ] 1. Пълнотекстово търсене по заглавие, описание, критерии и проследимост.
- [ ] 2. Филтри по ID, префикс, статус, приоритет, отговорник.
- [ ] 3. Търсене по връзки (деца/родители/зависимости).
- [ ] 4. Бърз отговор при големи бази (индексиране).
