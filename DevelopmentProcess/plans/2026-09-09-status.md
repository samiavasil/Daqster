## Design Decisions (agreed 2026-09-09)
1. **Workspace = separate .flow file (literally)** — each workspace is a self-contained graph
2. **Inter-workspace communication = via existing network nodes** (NetworkSource/NetworkSink) — NOT RPC infra; user explicitly places network nodes in workspaces
3. **Workspaces switch via tabs**
4. **Widgets dockable/undockable** — dynamic layout control in BOTH editor and runtime modes
5. **Launch**: `--run flow1.flow flow2.flow` (multiple args) + ui section per-flow (each .flow knows its own layout)
6. **Video unification**: ONE display concept — `VideoDisplayWidget` interface:
   - `VideoGLBlitWidget` (QOpenGLWidget, GPU, ~15% CPU) — default
   - `VideoSoftwareWidget` (QWidget + paintEvent, CPU) — fallback when no GPU/OpenGL (auto-detect)
   - Both layout-friendly (QWidget subclasses), both work detached (editor floating) + embedded (runtime layout)
   - REMOVE: in-node display (Qt5 QLabel ~34% CPU, Qt6 QGraphicsVideoItem), Qt6 native QVideoWidget (QTBUG-35299 — cannot embed)
7. **Layout schema v2**: workspaces with dock layouts, layout tree serialization (NOT binary blob), per-flow ui section
