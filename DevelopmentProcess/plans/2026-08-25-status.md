## What was built

1. **`VideoGLShaders.h`** — shader builders extracted from `VideoGLBlitWidget.cpp`
   (`buildVertexSource`, `buildYuvFragmentSource`, `buildRgbaFragmentSource`) as
   `inline` functions + new `buildEffectFragmentSource(core, nv12, effectBody)`
   with `u_flipY` texture-coordinate flip and injectable effect body.
2. **`VideoEffectOps.{h,cpp}`** — `EffectParams` + `EffectSpec` (id, displayName,
   Backend CpuOnly/GpuOrCpu, cpuApply, glslBody) + `allSpecs()` (7 effects) +
   `specFor(id)`. CPU functions delegate to `VideoTransformOps`.
3. **`VideoEffectGLProcessor.{h,cpp}`** — GPU backend: own QOpenGLContext +
   QOffscreenSurface, per-(effect,layout,profile) program cache, Y/U/V upload with
   `GL_UNPACK_ROW_LENGTH`, FBO render + `toImage()` readback, lazy-cached
   `hasHardwareGL()` (llvmpipe/softpipe/SwiftShader detection).
4. **`VideoEffectNode.{h,cpp}`** — node model (port 0 in/out `VideoFrameData`),
   runtime backend selection, CPU/GPU paths, param-change reprocess, save/load
   with clamps, per-effect parameter UI + 7 thin subclasses (no Q_OBJECT).
5. **`FrameSamplerNode.{h,cpp}`** — every-N-th / max-fps gating, zero-copy
   shared_ptr passthrough, save/load + gate reset, combo + spinbox UI.
6. **CMake + registration** — new sources in `VIDEO_NODES`, 7 VideoEffect* +
   FrameSampler registered under "Video".
7. **Smoke drivers** — `DAQSTER_AUTOSTART_EFFECT=<effectId>` inserts a VideoEffect
   node between source and output; `DAQSTER_AUTOSTART_SAMPLER=1` inserts a
   FrameSampler. Fixed to use `connectionExists` (not `connectionPossible`) when
   rewiring the existing source→output connection.

## Notes / risks

- On this machine offscreen GL still reports the NVIDIA renderer, so the plan's
  assumption "offscreen = llvmpipe → CPU backend" does NOT hold; the CPU backend
  was verified via the non-YUV-frame fallback instead.
- GPU flip effect flips VERTICALLY (via `u_flipY`); the CPU path honors the
  horizontal/vertical combo. Documented Phase-1 simplification (Phase 3 can add
  horizontal flip to the shader).
- All 7 effects are `GpuOrCpu`; the `CpuOnly` backend mechanism is implemented
  but currently unused (AC 3 satisfied by mechanism).
- Qt5 test link initially failed in a fresh build dir because CMake resolved
  `Qt5_DIR` to the SYSTEM Qt 5.15.13; fixed by forcing
  `-DQt5_DIR=/mnt/Builder/bin/Linux/Qt/5.15.2/gcc_64/lib/cmake/Qt5`.
- PL-028/PL-030 AC 6 (unit tests) remain deferred per standing instruction.
