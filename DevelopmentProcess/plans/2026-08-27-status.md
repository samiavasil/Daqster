## REQ-SW-PL-034 — VideoOutputNode embedded effects (2026-08-27, комит `615f53e`)

- **Имплементирано:** Display нодът (`VideoOutputNode`) получи **опционални
  вградени ефекти** — същите 11 ефекта като `VideoEffectNode`, **без ефект по
  подразбиране** (комбобокс с водещ „No effect" index 0 + `m_effectEnabled`).
- **Zero-copy гаранция (AC 2):** при липса на ефект блокът в `setInData()`
  се пропуска изцяло — `asTexture()`/`asImage()` не се викат, display пътят е
  byte-identical на предишната версия.
- **Backend:** GPU path (`asTexture()` → `VideoEffectGLProcessor::processTexture()`
  → `fromTexture()`, GpuRgba zero-copy) при хардуерен GL; CPU path/fallback
  (`asImage()` → `EffectSpec::cpuApply` → `QVideoFrame`).
- **Persist:** `save()`/`load()` — `"effect"` id + параметри с clamp-ове;
  стари графи без `"effect"` ключ → „no effect" (backward compatible).
- **Тестове:** `demo_nodeditor_videooutput_tests` +4 (default no-effect
  passthrough, load→save round-trip, backward compat, ефектът трансформира
  frame-а) — 10/10 на Qt5 и Qt6; ctest 9/9 green (и двете).
- **Забележка (отклонение от плана):** `setEffectIndex()` приема **combo index**
  (0 = „No effect"); `load()` мапва `indexOfEffect(id)` → combo index `+1`
  (планът казваше `setEffectIndex(indexOfEffect(id))` без +1 — това би избрало
  грешен ефект, тъй като combo index 0 е „No effect").
- **Файлове:** `VideoOutputNode.{h,cpp}`, `test_video_output_node.{h,cpp}`,
  `tests/plugins/demo_nodeditor_nodes/CMakeLists.txt` (VideoEffectOps/
  VideoTransformOps/VideoEffectGLProcessor добавени в test target),
  `REQ-SW-PL-034-video-output-node-embedded-effects.md` (AC 1–5 `[x]`),
