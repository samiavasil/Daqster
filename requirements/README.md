# Requirements — Daqster Framework Tools

Система за проследими изисквания за **общите инструменти и компоненти на
frame_work** в публичното Daqster repo. Изискванията на частните плъгини се
съхраняват в `requirements/` на съответното частно repo (напр. `DaqsterAiStudio`),
но инструментите тук могат да ги управляват също.

## Структура

```
requirements/
├── README.md              # Този файл
├── traceability-matrix.md # Матрица за проследимост (REQ ⟷ Коммит ⟷ Тест)
├── active/                # Активни (незавършени) изисквания
└── archive/               # Завършени/имплементирани изисквания
```

## Именуване

| Префикс | Област |
|---------|--------|
| `REQ-FW-XXX` | Общи инструменти/компоненти на frame_work |
| `REQ-PLG-XXX` | Plugin framework (откриване, зареждане, сигурност) |
| `REQ-DOC-XXX` | Документация и процеси |

За изисквания на **частни** репозитария (DaqsterAiStudio и др.) — използвай
техните собствени `REQ-*` префикси (`REQ-AI-*`, `REQ-SEC-*` …).

## Многоагентен работен процес

| Стъпка | Роля | Отговорност |
|--------|------|-------------|
| 1 | PM Agent | Дефинира REQ + Acceptance Criteria |
| 2 | Architect Agent | Проверява архитектурната съвместимост |
| 3 | Implementation Agent | Кодира и линква коммита към REQ ID |
| 4 | QA Agent | Пише тестове по Acceptance Criteria и верифицира |
